# 🤖 Herobot-Llama

**Herobot-Llama** is a lightweight AI chatbot written in **Java** that uses **Ollama** to run the **Llama 3.2 1B** model locally. It also features **Internet search capabilities**, allowing the chatbot to retrieve up-to-date information when the model's built-in knowledge isn't enough.

The goal of Herobot-Llama is to provide a simple, fast, and extensible open-source AI assistant that can run on consumer hardware while keeping user data local.

---

* 🦙 Powered by **Llama 3.2 1B** via **Ollama**
* ☕ Built entirely in **Java**
* 🌐 Internet search for real-time information
* 💬 Interactive chatbot interface
* ⚡ Lightweight and efficient
* 💻 Runs locally on your computer
* 🔓 Open source
* 🛠 Easy to modify and extend

# Why Herobot-Llama?

Running AI locally provides several advantages:

* Better privacy
* No expensive cloud API costs
* Faster response times for local inference
* Full control over your AI assistant

Herobot-Llama combines the power of a local LLM with Internet search, allowing it to answer both general and current-event questions.

* Java 17 or newer

# Installing Ollama

Install Ollama from:

**https://ollama.com**

Then download the model:

```bash
ollama pull llama3.2:1b
```

Start the Ollama server:

```bash
ollama serve
```

# How It Works

1. The user enters a prompt.
2. Java sends the prompt to the local Ollama server.
3. Ollama generates a response using **Llama 3.2 1B**.
4. If needed, Herobot-Llama performs an Internet search.
5. Search results are incorporated into the final response.
6. The answer is displayed to the user.
